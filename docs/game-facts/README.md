# Game facts: observed values

This folder is where whole tables of observed game values (trick lists, gap lists, stat tables) would go, written as **facts about
the game** in our own arrangement. For Tony Hawk's Pro Skater 3 **no value tables are published in v0.1**; the layouts and addresses
the recomp needs are in [docs/internals/](../internals/recomp.md).

**The policy** (what a documentation page may contain, and the linter that enforces it): addresses, sizes, counts, strides, hashes,
header fields, names, struct layouts and algorithms, anywhere; individual constants with their address, anywhere; full tables of
entity-keyed values only in this folder. Never, anywhere: ROM bytes or hex runs, assembly or decompiled source, textures, models,
audio, renders, screenshots or video, dialogue and long descriptions.
